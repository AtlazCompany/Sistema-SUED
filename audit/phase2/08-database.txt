CÓDIGO (server/utils.js prepInsert) ESPERA: toda tabela populada via
  prepInsert() ganha createdAt e updatedAt automaticamente.
BANCO POSSUI: a tabela "User" NÃO TEM as colunas createdAt/updatedAt.
  Isso não causa problema porque nenhuma rota usa prepInsert() para
  criar User — as novas rotas de criação de usuário (Fase 2) montam o
  registro manualmente, sem essas colunas, exatamente por isso.
  CONFIRMADO nesta fase por tentativa real de INSERT com essas colunas,
  que falhou com "column does not exist" — usado para corrigir o código
  ANTES de ele ir para produção (o server/routes/usuarios.js já foi
  escrito sem createdAt/updatedAt, então não houve bug em produção, só
  uma confirmação da hipótese já registrada como incerteza na auditoria
  de schema anterior).
