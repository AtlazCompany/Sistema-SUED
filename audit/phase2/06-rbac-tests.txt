SUED SYSTEM — FASE 2 — 06. TESTES DE RBAC (matriz real via HTTP)
=============================================================
Metodologia: NÃO foi testado só o frontend nem só a lógica unitária.
Para cada um dos 5 papéis, foi criado um usuário de teste real
(audit.fase2.<papel>@sued.local), foi feito login real via
POST /api/auth/login, e o cookie de sessão retornado foi usado para
chamar diretamente o endpoint GET representativo de cada um dos 10
módulos (9 módulos de negócio + o novo módulo "usuarios"). Resultado
esperado: permitido -> 200, não permitido -> 403, não autenticado -> 401.

RESULTADO: 51/51 CHECAGENS PASS (50 combinações papel x módulo + 1
checagem de acesso sem autenticação). ZERO FALHAS.

OBSERVAÇÕES
-------------
- Todos os valores "obtido" bateram exatamente com "esperado" — nenhuma
